# InclinoCar

Rooftop tent leveling assistant using ESP32-C3 and MPU-6050.

## Hardware

| Component | Pins |
|-----------|------|
| SSD1306 OLED 128×64 | SDA→GPIO3, SCL→GPIO4 |
| MPU-6050 GY-521 | SDA→GPIO6, SCL→GPIO7, AD0→GND |

## Install

Flash via the **[Web Installer](https://tophe75.github.io/inclinocar/)** in Chrome or Edge.
