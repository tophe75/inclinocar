INCLINOCAR
Rooftop Tent Leveling System
What this installs: Firmware for the ESP32-C3 Core Unit. Reads pitch & roll from the MPU-6050 and displays it on the OLED screen.

Requirements: Chrome or Edge browser on desktop. Hold the BOOT button on the ESP32-C3, plug in USB, then release.
Web Serial is not supported in this browser.
Please use Chrome or Edge on desktop.
