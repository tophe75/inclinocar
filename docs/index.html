ESP32 #1

Core Unit

Mounts on the roof rack or tent. Reads pitch & roll, shows angles on its OLED, streams data over BLE to the phone and via ESP-NOW to the Satellite Display.

ESP32 #2

Satellite Display

Optional remote display unit. Place it inside the car or tent. Receives angle data from the Core Unit via ESP-NOW — no IMU, no phone needed.

Unsupported browser. This installer uses the Web Serial API which requires Chrome 89+ or Edge 89+ on desktop. Firefox and Safari are not supported.
01

Select Firmware

Choose which unit you are flashing. Always flash the Core Unit first.

Core Unit — ESP32 #1 MPU-6050 IMU · OLED display · BLE · ESP-NOW TX · Cal button
Satellite Display — ESP32 #2 OLED display only · ESP-NOW RX · No IMU · No BLE
Core Unit — the main sensor node. Measures tent pitch & roll, displays angles locally on its OLED, broadcasts over BLE to the phone app, and sends data to the Satellite Display via ESP-NOW. Hold the calibration button for 1 second to reset the level reference.

02

Connect ESP32-C3

○

Hold the BOOT button on the ESP32-C3, plug in USB, then release BOOT. Click connect and select the correct COM port.

ESP32-C3 built-in USB: Hold BOOT, plug in, release BOOT — shows as USB Serial Device (VID 303A)
Windows: May need CP210x drivers for USB-UART adapter boards
If the list is empty: The port dialog shows nothing if no serial device is detected — check USB cable and BOOT button sequence
